# Security Policy

## Supported versions

APG is currently a developer preview. Security fixes are applied to the latest
published preview and the current `main` development line. Older preview
releases may not receive fixes.

## Report a vulnerability

Do not open a public Issue for an exploitable vulnerability or include secrets,
tokens, private repository data, or working exploit details in public logs.

Use GitHub's
[private vulnerability reporting form](https://github.com/jayjcc8-cloud/agent-project-governance/security/advisories/new)
and include:

- affected version or commit;
- impact and affected component;
- reproduction steps or a minimal proof of concept;
- any known mitigation.

Maintainers will acknowledge the report, assess severity and scope, and keep the
reporter informed when there is meaningful progress. Preview status means a
fixed response deadline cannot yet be guaranteed. Coordinated disclosure will
be discussed before public details are released.
